# deploy

Deployment-Skripte für das Setup von Linuxumgebungen

# Nutzung

Die Skripten können direkt mit curl aus dem Repository ausgeführt werden. Dazu wird mit curl das Skript abgerufen und an `sh` gepiped.

## Latest Version

`curl https://raw.githubusercontent.com/SteGab/deploy/refs/heads/main/toolbox/setup-toolbox.sh | sh`

## Spezifische Version (Tag)

`curl https://raw.githubusercontent.com/SteGab/deploy/refs/tags/v1.0/toolbox/setup-toolbox.sh | sh`
